# devsecops-security-scanner
Framework automatizado e modular de reconhecimento, OSINT e auditoria de segurança voltado para pipelines DevSecOps e testes de intrusão autorizados. Inclui detecção de WAF, enumeração de diretórios assíncrona, escaneamento de portas de alta performance e geração automática de relatórios em JSON e HTML.
